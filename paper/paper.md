# Summary

MEGaNorm is a Python package for large-scale analysis of electroencephalography (EEG) and magnetoencephalography (MEG) recordings. EEG records electrical potentials at the scalp, while MEG records magnetic fields generated by neural activity. Both help researchers study brain function. MEGaNorm combines preprocessing, automated quality checks and visual inspection, optional source localization, extraction of imaging-derived phenotypes (IDPs), integration of participant information, and normative modeling into a single workflow. The resulting models describe the range of brain measures expected in a reference population given age or other traits and quantify how each person compares to that range. This supports research on individual differences in brain function and precision neuropsychiatry. The workflow supports both sensor- and source-level analysis and runs on local computers or SLURM clusters. Source code, documentation, and archived releases are available through [GitHub](https://github.com/ML4PNP/MEGaNorm), [Read the Docs](https://meganorm.readthedocs.io/), and the [Zenodo concept DOI](https://doi.org/10.5281/zenodo.15441319).

# Statement of need

Normative modeling [@marquand2016beyond] of brain measures depends on reference data that capture variation in the population of interest. To cover broad age ranges and diverse populations, EEG/MEG studies often pool recordings from several cohorts and sites. These datasets can differ in recording systems, sensor configurations, file organization, signal quality, preprocessing needs, and the format and coding of participant information. Researchers must also keep IDP definitions and participant identifiers consistent across these sources. Together, these requirements make multisite analyses difficult to set up, check, and reuse.

MEGaNorm addresses these practical needs for researchers using EEG/MEG to study brain development, aging, and differences between individuals or clinical groups. Its documented, configurable workflow reduces the need to rebuild scripts for cohort processing and normative modeling, while leaving researchers in control of processing steps, IDP definitions, and model design.

# State of the field

Several pipelines already standardize or automate EEG/MEG processing. For EEG, PREP [@bigdely2015prep], HAPPE [@gabard2018harvard], and Automagic [@pedroni2019automagic] automate preprocessing of large datasets, and DISCOVER-EEG [@gil2023discover] extends this to feature extraction from resting-state recordings. For MEG, FLUX [@ferrante2022flux] provides notebooks with explicit processing and analysis settings, including source analysis of oscillatory activity; MEGPrep [@megprep] and MEGAP [@mohammadi2025megap] automate preprocessing; and the ENIGMA MEG pipeline [@enigmameg] automates source-level spectral analysis of multisite resting-state data. MNE-BIDS-Pipeline [@jas2018reproducible] supports both modalities, covering processing from raw recordings to sensor- and source-level results, including evoked responses, time-frequency representations, and decoding.

For normative studies, a further task is to connect IDP extraction with cohort assembly, model fitting, and application to new recordings. Applying an existing model requires IDP definitions and processing settings compatible with those used for training. These connections span several libraries, so keeping them in a separate package lets the workflow be developed and reused as a whole. MEGaNorm provides this layer by linking recording-level processing, cohort data preparation, and normative analysis using PCNtoolkit [@rutherford2022]. Its contribution lies in coordinating data, settings, and execution across these stages while drawing on established methods.

# Software design

MEGaNorm separates IDP extraction and cohort assembly from normative modeling (\autoref{fig:architecture}), allowing saved IDPs to be reused across modeling analyses without repeating signal processing. The `meganorm.src` modules implement signal processing, source localization, IDP extraction, and modeling; `meganorm.utils` handles configuration, files, participant data, and job management; and `meganorm.plots` provides plots for quality control, spectral inspection, and model evaluation. Processing settings and dataset layouts are kept separate so you can reuse analysis settings with different data sources. JSON configuration files define processing steps and parameters and are validated with Pydantic before processing begins. Dataset layouts specify paths and file patterns for recordings and participant information.

Each recording is processed independently using established analysis libraries. MNE-Python [@gramfort2013] supports preprocessing and source reconstruction. After preprocessing and quality control, IDPs can be extracted from sensor epochs or reconstructed source activity, grouped by brain region. The optional source step therefore precedes spectral extraction. SpecParam [@donoghue2020] models periodic peaks and the aperiodic background of power spectra. PyRASA [@schmidt2025pyrasa] implements irregular-resampling auto-spectral analysis (IRASA) [@wen2016] to separate these components. Saved configurations, processing logs, and quality-control outputs document how researchers obtained the IDPs; they can also retain intermediate data, such as preprocessed recordings and power spectra.

Cohort assembly links the extracted IDPs with participant information in a single table for modeling. Researchers specify response measures, covariates, and batch-effect variables. MEGaNorm prepares these data for PCNtoolkit [@rutherford2022], which fits models, makes predictions, and evaluates performance. MEGaNorm provides plots of reference trajectories and individual deviations. 

Local and cluster execution use the same core processing functions through different entry points. The `meganorm.API` layer provides a Python interface for sequential participant processing and local model fitting. SLURM entry points distribute recordings across independent jobs, allowing failed jobs to be resubmitted without rerunning successful ones. The existing modeling functions can also distribute fitting across response measures using PCNtoolkit's `Runner`. Separating processing configuration from scheduler settings lets the researcher reuse analysis settings across computing environments.

Tests and documentation support usage and maintenance of the workflow. Automated tests covering processing, IDP extraction, data handling, plotting, and model integration run through GitHub Actions. Sphinx documentation provides installation instructions, API descriptions, and worked examples.

# Research impact statement

MEGaNorm supported the published study of normative MEG brain oscillations across the human lifespan [@zamanzadeh2026]. The study used recordings from 1,846 reference participants aged 6-88 years, drawn from several datasets and recording systems, and applied the resulting models to a separate Parkinson's disease cohort. We used MEGaNorm for preprocessing, model training, statistical analysis, and figure generation. The Communications Biology article reports the scientific findings and validation for that study; the present paper describes the reusable software that supported the work.

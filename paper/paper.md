# Summary

Electroencephalography (EEG) and magnetoencephalography (MEG) measure the electrical and magnetic fields generated by neural activity, providing a non-invasive window into brain function. Despite the availability of many software packages for M/EEG analysis, a single automated and configurable workflow that enables large-scale, multisite analysis of such recordings is lacking. MEGaNorm is a Python package that fills this gap. It integrates data preprocessing, manual and automated quality control, source localization, imaging-derived phenotypes (IDPs) extraction, participant-level information, and normative modeling into one end-to-end workflow. Normative models characterize the expected range of brain measures in a reference population, allowing individual differences to be quantified relative to these population norms. Owing to its end-to-end design, MEGaNorm facilitate the establishment and application of normative models of M/EEG in research and clinical settings. Source code, documentation, and archived releases are available on [GitHub](https://github.com/ML4PNP/MEGaNorm), [Read the Docs](https://meganorm.readthedocs.io/), and [Zenodo](https://doi.org/10.5281/zenodo.15441319).

# Statement of need

Large-scale analysis such as normative models [@marquand2016beyond; @rutherford2022] require large and diverse samples, which in EEG and MEG research often necessitates pooling data across multiple cohorts and sites. In practice, this is challenging because datasets can differ substantially in recording systems, sensor configurations, file organization, signal quality, preprocessing requirements, and the format and coding of participant information. These practical barriers, among other factors, have limited the scalability of multisite studies of human electrophysiology. The absence of standardized workflows also means that established normative models cannot easily be extended to new sites, which limits decentralized (federated) learning, nor easily applied in clinical or research settings with different levels of expertise.

MEGaNorm addresses these challenges by providing a single, documented workflow for large-scale normative modelling of M/EEG data. Starting from raw recordings, it performs preprocessing and quality control, extracts IDPs at the sensor or source level using consistent definitions, and integrates them with participant-level information. Although MEGaNorm can be used on its own to extract IDPs, it also provides an end-to-end workflow that uses these IDPs to fit normative models and produces visualizations that help interpret individual deviations from the norm. Processing steps are controlled through documented configuration files, allowing researchers to retain control over analysis choices. The same workflow can run on a local machine or be distributed across SLURM-managed computing clusters, making analyses involving thousands of recordings feasible. MEGaNorm is intended for researchers using EEG and MEG to investigate brain development, aging, and individual or clinical differences. By replacing study-specific scripts with a shared and reusable workflow, it makes normative analyses of large-scale electrophysiological data easier to implement, reproduce, and validate, while facilitating more consistent comparisons across datasets and studies. 

# State of the field

While there are many well-established open-source packages for M/EEG analysis, none provides a configurable, automated, and end-to-end pipeline for normative modeling of electrophysiological data. MNE-Python supports preprocessing, source reconstruction, and spectral analysis [@gramfort2013], but provides building blocks for individual processing steps rather than a complete pipeline. Several pipelines build on these methods: FLUX offers standardized, notebook-based MEG analyses intended mainly for training and task-based studies [@ferrante2022flux], MEGPrep and MEGAP[@mohammadi2025megap] automates MEG preprocessing, and MNE-BIDS-Pipeline automates M/EEG processing from raw recordings to sensor- and source-level results such as evoked responses, time-frequency representations, and decoding [@mnebids_pipeline]. However, none of these extracts standardized IDPs across multiple sites. The ENIGMA MEG pipeline [@enigmameg] goes further by automating source-level spectral analysis of multisite resting-state MEG data, but it is limited to MEG and a predefined set of analyses and configuration and does not support normative modeling. Finally, while PCNtoolkit provides normative modeling methods for studying individual differences [@rutherford2022], it requires IDPs to be extracted beforehand and does not process raw recordings.

Building or applying normative models from multisite M/EEG data therefore requires researchers to combine multiple packages into a complete workflow themselves, from preprocessing and IDP extraction to the preparation of data for normative modeling, while keeping all steps consistent across datasets and recording systems. Because this integration spans multiple libraries and processing stages, it is typically implemented through study-specific scripts. This hampers reproducibility and makes it difficult to apply existing normative models to new data, which must be processed in the same way as the data used to train them.

MEGaNorm provides this missing workflow layer. while relying on established packages for the underlying methods, tt connects recording-level processing with cohort assembly and downstream normative analysis. Its contribution is therefore not to reimplement existing algorithms, but to integrate them into a documented, configurable, and reusable workflow that maintains consistency across datasets and processing stages.

# Software design

MEGaNorm separates IDP extraction and cohort assembly from normative modeling (\autoref{fig}), allowing researchers to extract IDPs independently and reuse them across modeling analyses without repeating computationally expensive signal processing. The software is organized into `meganorm.src`, which implements signal processing, IDP extraction, and modeling; `meganorm.utils`, which handles configuration, files, participant data, and job management; and `meganorm.plots`, which provides visualizations for quality control, spectral inspection, and normative model evaluation.

Processing settings are defined in JSON configuration files and validated with Pydantic before processing begins. Dataset layouts are specified separately through paths and file patterns for recordings and participant information. MEGaNorm therefore does not require a Brain Imaging Data Structure (BIDS)-compliant organization, accommodating differences across studies and sites, provided that each dataset has a consistent structure described by the user. Each recording is processed independently, including preprocessing, quality control, and IDP extraction from sensor-level data or, optionally, source activity reconstructed with MNE-Python. Extracted IDPs are saved alongside demographic information, and cohort utilities combine these data into a single dataframe. For each analysis, MEGaNorm saves the configuration, processing logs, and quality-control outputs; intermediate data, such as preprocessed recordings and power spectra, can also be retained.

The normative modeling component prepares the assembled cohort data for PCNtoolkit, which performs model fitting, prediction, and evaluation. Researchers specify response measures, covariates, and batch-effect variables, while MEGaNorm provides tools to visualize reference trajectories and individual deviations. Reusing extracted IDPs requires consistent IDP definitions and participant identifiers, and researchers must assess comparability across recording systems.

Local and cluster execution use the same core processing functions through different entry points. The `meganorm.API`provides sequential processing through the Python interface, while SLURM entry points distribute recordings across independent jobs, allowing failed jobs to be resubmitted without rerunning successful ones. Model fitting can also be distributed across response measures using PCNtoolkit's `Runner`. Separating processing configuration from scheduler settings allows analysis settings to be reused across computing environments. Automated tests covering processing, IDP extraction, data handling, plotting, and model integration run through GitHub Actions; Sphinx documentation provides installation instructions, API descriptions, and worked examples.

# Research impact statement

MEGaNorm supported the published study of normative MEG brain oscillations across the human lifespan [@zamanzadeh2026]. The study used recordings from 1,846 reference participants aged 6-88 years, drawn from several datasets and recording systems, and applied the resulting models to a separate Parkinson's disease cohort. We used MEGaNorm for preprocessing, model training, statistical analysis, and figure generation. The Communications Biology article reports the scientific findings and validation for that study; the present paper describes the reusable software that supported the work.

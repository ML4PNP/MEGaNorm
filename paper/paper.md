# Summary

Electroencephalography (EEG) and magnetoencephalography (MEG) measure the electrical and magnetic fields generated by neural activity, providing a non-invasive window into brain function. Despite the availability of many software packages for M/EEG analysis, a single automated and configurable workflow that enables large-scale, multisite analysis of such recordings is lacking. MEGaNorm is a Python package that fills this gap. It integrates data preprocessing, manual and automated quality control, source localization, feature extraction, participant-level information, and normative modeling into one end-to-end workflow. Normative models characterize the expected range of brain measures in a reference population, allowing individual differences to be quantified relative to these population norms. Owing to its end-to-end design, MEGaNorm facilitate the establishment and application of normative models of M/EEG in research and clinical settings. Source code, documentation, and archived releases are available on [GitHub](https://github.com/ML4PNP/MEGaNorm), [Read the Docs](https://meganorm.readthedocs.io/), and [Zenodo](https://doi.org/10.5281/zenodo.15441319).

# Statement of need

Reliable normative models [@marquand2016beyond; @rutherford2022] require large and diverse samples, which in EEG and MEG research often necessitates pooling data across multiple cohorts and sites. In practice, this is challenging because datasets can differ substantially in recording systems, sensor configurations, file organization, signal quality, preprocessing requirements, and the format and coding of participant information. These practical barriers, among other factors, have limited the scalability of multisite studies of human electrophysiology. The absence of standardized workflows also means that established normative models cannot easily be extended to new sites, which limits decentralized (federated) learning, nor easily applied in clinical or research settings with different levels of expertise.

MEGaNorm addresses these challenges by providing a single, documented workflow for large-scale normative modeling of EEG and MEG data. Starting from raw recordings, it performs preprocessing, extracts imaging-derived phenotypes (IDPs) at the sensor or source level using consistent definitions, integrates them with participant-level information, fits normative models, and produces visualizations that help interpret individual deviations from the norm. Processing steps are controlled through documented configuration files, allowing researchers to retain control over analysis choices. The same workflow can run on a local machine or be distributed across SLURM-managed computing clusters, making analyses involving thousands of recordings feasible.  MEGaNorm is intended for researchers using EEG and MEG to investigate brain development, aging, and individual or clinical differences. By replacing study-specific scripts with a shared and reusable workflow, it makes normative analyses of electrophysiological data easier to implement, reproduce, and validate, while facilitating more consistent comparisons across datasets and studies. Although designed for normative modeling, MEGaNorm can also be used on its own to extract IDPs from EEG and MEG recordings.

# State of the field

Established open-source packages provide the core methods for EEG and MEG analysis. MNE-Python supports preprocessing, source reconstruction, and spectral analysis [@gramfort2013]. MNE-BIDS reads and writes data in the Brain Imaging Data Structure (BIDS) format [@appelhoff2019], and MNE-BIDS-Pipeline builds on both to automate processing from raw recordings to source estimates [@mnebids_pipeline]. Two packages separate the periodic and aperiodic components of power spectra: SpecParam models periodic peaks and the aperiodic background [@donoghue2020], and PyRASA implements irregular-resampling auto-spectral analysis (IRASA) [@schmidt2025pyrasa; @wen2016]. For downstream analysis, PCNtoolkit provides normative modeling methods for studying individual differences [@rutherford2022].

These packages primarily focus on individual processing steps or individual datasets. Combining them for multi-cohort analyses still requires researchers to define and maintain consistent IDPs, align extracted features with participant-level information, prepare data for normative modeling, and coordinate processing across datasets and computational resources. Because these tasks span multiple libraries and occur between processing stages, they are not naturally addressed by any single existing package and are typically implemented through study-specific scripts.

MEGaNorm provides this missing workflow layer. It connects recording-level processing with cohort assembly and downstream normative analysis, while relying on established packages for the underlying methods. Its contribution is therefore not to reimplement existing algorithms, but to integrate them into a documented, configurable, and reusable workflow that maintains consistency across datasets and processing stages.

# Software design

MEGaNorm separates participant processing, cohort assembly, and normative modeling into three stages (\autoref{fig:architecture}). The `meganorm.src` modules carry out signal processing, feature extraction, and modeling steps. The `meganorm.utils` modules handle settings, files, participant data, and SLURM jobs. The `meganorm.plots` modules provide plots for checking processing, inspecting spectra, and viewing reference curves and individual deviations.

JSON configuration files record the processing steps and settings used for each dataset. The participant entry point loads a recording, filters it, handles artifacts, and splits it into epochs. You can extract IDPs from sensor epochs or from source activity reconstructed with MNE-Python, then group them into brain regions using anatomical inputs. This optional source step precedes spectral extraction. SpecParam or PyRASA then supports extraction of periodic and aperiodic measures, power in fixed or person-specific frequency bands, and band-power ratios. Sensor layouts allow summaries across all sensors or within chosen regions. Features are saved with a processing log and, when requested, intermediate data and reports.

Saved participant feature tables let researchers refit models for the same IDPs without repeating signal processing. Utilities join these tables across the cohort and link them with participant data. Researchers select the response measures, covariates, and batch-effect variables; data-preparation helpers then build PCNtoolkit `NormData` objects. PCNtoolkit fits, predicts, and evaluates models using the chosen regression templates, while MEGaNorm provides model checks and plots of centiles and deviations. This stage requires matching participant IDs and consistent feature definitions. Researchers must also assess whether measurements can be compared across recording systems.

Local and cluster execution use the same core processing functions through different entry points. The `meganorm.API` layer provides a Python interface for local cohort processing and model fitting; participant processing is sequential. Cluster workflows use separate SLURM entry points to process participant recordings in independent jobs, so each process loads only the recording it needs. The existing modeling functions can also use PCNtoolkit's `Runner` to distribute model fitting across response measures. Processing configuration is separate from scheduler settings, allowing you to reuse processing steps across computing environments. Users supply the cluster environment and resource requests.

Tests and documentation support maintenance of the workflow and its links to upstream libraries. Automated tests cover core processing, feature extraction, data handling, plotting, and model integration, and run through GitHub Actions. Sphinx documentation provides installation instructions, API descriptions, and worked examples.

# Research impact statement

MEGaNorm supported the published study of normative MEG brain oscillations across the human lifespan [@zamanzadeh2026]. The study used recordings from 1,846 reference participants aged 6-88 years, drawn from several datasets and recording systems, and applied the resulting models to a separate Parkinson's disease cohort. We used MEGaNorm for preprocessing, model training, statistical analysis, and figure generation. The Communications Biology article reports the scientific findings and validation for that study; the present paper describes the reusable software that supported the work.
